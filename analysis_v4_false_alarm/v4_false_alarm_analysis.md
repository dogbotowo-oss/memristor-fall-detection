# v4 Subject4 ADL 误报分析

## 基本结果

v4_penalty0 在 Subject4 独立测试中的 ADL 误报为 4 个：

- `ADL/05.mp4`
- `ADL/11.mp4`
- `ADL/12.mp4`
- `ADL/19.mp4`

- `F:\12.18-2\analysis_v4_false_alarm\v4_false_alarm_contact_sheet.jpg`

## 逐个分析

| 视频 | 检测片段 | 峰值分数 | 误报形态 | 初步归因 |
|---|---:|---:|---|---|
| ADL/05 | 3.75-7.26 s | 0.598 | 低头、双手撑地、身体趴低/接近爬行 | 与真正跌倒后的俯卧、撑地起身阶段相似 |
| ADL/11 | 6.60-7.40 s | 0.812 | 蹲坐在地面附近，手部在地面操作 | 与跌倒后坐地/低位停留高度相似 |
| ADL/12 | 0.00-0.40 s | 0.763 | 视频开头即坐地/低姿态 | 初始帧就是低位姿态，模型缺少“已坐地但非跌倒”的上下文 |
| ADL/19 | 0.00-0.47 s | 0.553 | 人物从画面边缘进入，只有部分身体可见 | 视频边界/入画阶段触发，属于短时边界误报 |

## 关键判断

1. 误报并不集中在单一 Activity9 类型。

   Activity9 一般更接近 picking up object / 弯腰捡东西，但 v4 的误报中至少包括：

   - 趴低/撑地/接近爬行：ADL/05
   - 蹲坐/坐地/地面操作：ADL/11、ADL/12
   - 入画边界短时触发：ADL/19

   因此，单纯补更多 Activity9 不一定能解决 v4 的主要误报。

2. ADL/11 和 ADL/12 是最像“需要补 hard negative”的类型。

   这两个视频不是短暂噪声，而是模型对低位人体姿态产生强烈 fall 判断：

   - ADL/11：整段几乎被模型视为 fall，峰值 0.812。
   - ADL/12：视频开头就是坐地低姿态，峰值 0.763。

   这说明模型缺少“人主动蹲下/坐地/地面操作但没有跌倒”的训练约束。

3. ADL/05 更像“四肢撑地/趴低/起身” hard negative。

   这种动作和真正跌倒后的 post-fall 姿态非常接近。直接把它作为 normal hard negative 有价值，但权重不能过大，否则可能压低真正 Fall recall。

4. ADL/19 更像后处理或边界规则问题。

   它只在视频开头 0.47 s 触发，而且人物只部分入画。这类问题不一定需要靠训练解决，更适合用：

   - 开头若干帧忽略策略
   - 需要检测片段具有更长持续时间
   - 要求过程段前后具有足够上下文
   - 入画/出画边界过滤

## 对新增 ADL 数据的启示

优先补充的数据类型不应只限于 Activity9，而应按 v4 误报形态补：

1. 坐地/坐床/坐椅子后身体低位停留。
2. 蹲下捡东西、蹲坐在地面附近操作。
3. 双手撑地、趴低、爬行、从地面起身但不是跌倒。
4. 人物从画面边缘进入/离开、只露出部分身体的短片段。

其中 1、2、3 适合作为训练 hard negative；第 4 类更适合做后处理规则或验证集检查。

## 下一步建议

1. 不建议继续只加 Activity9。
2. 优先从新增 ADL 数据集中筛选类似 ADL/11、ADL/12 的“蹲坐/坐地/地面操作”片段。
3. 第二优先筛选类似 ADL/05 的“撑地/趴低/爬行/起身”片段，但采样权重要低，防止压低 Fall recall。
4. 对 ADL/19 这类短时开头误报，优先考虑后处理边界过滤，不建议作为主要训练方向。
